# คู่คิดติวสอบเข้า ม.1 — คณิตศาสตร์ & ภาษาอังกฤษ (ระดับโรงเรียนแข่งขันสูง)

ระบบฝึกทำข้อสอบ วิเคราะห์จุดอ่อนรายทักษะ และติวเตอร์ส่วนตัวสำหรับนักเรียน ป.6 ที่เตรียมสอบเข้า ม.1 โรงเรียนชั้นนำ (สวนกุหลาบ, สาธิต, เตรียมอุดมศึกษาน้อย, ห้องเรียนพิเศษ Gifted / EP / SMTE)

## จุดเด่นของระบบ

1. **คลังโจทย์หลากหลายระดับสอบเข้าจริง (Procedural + Visual Bank)**
   - ครอบคลุม **13 บทหลัก** (คณิตศาสตร์ 8 บท · ภาษาอังกฤษ 5 บท) แยกย่อยกว่า **80+ ทักษะ (Skills)** และมีระดับความยาก 4 ระดับ (`ง่าย`, `ปานกลาง`, `ยาก`, `ท้าทาย`)
   - โจทย์ถูกสร้างสดใหม่ด้วยพารามิเตอร์และตรวจคำตอบด้วยโปรแกรม เก็บลงฐานข้อมูล SQLite (`backend/tutor.db`) ข้อที่เคยออกแล้วจะไม่ถูกนำมาซ้ำ
   - **เห็นภาพชัดเจน**: มีรูปเรขาคณิต SVG, มุมและเส้นขนาน, พื้นที่แรเงา, รูปเรขาคณิต 3 มิติ, แผนภูมิแท่ง/วงกลม/กราฟเส้น, เส้นจำนวน, แถบเศษส่วน, นาฬิกา, ตารางข้อมูล และแสดงผลเศษส่วนซ้อนจริง

2. **เสมือนมีติวเตอร์คู่คิดส่วนตัว (Interactive Personal Tutor)**
   - **📖 บทเรียนรายทักษะ (Mini-Lessons)**: สรุปหลักคิดสำคัญ ขั้นตอนการแก้โจทย์ ตัวอย่างพร้อมวิธีทำ โจทย์สาธิตที่สุ่มสร้างสดใหม่ กับดักที่เด็กมักพลาด และเทคนิคคิดเร็ว
   - **🧑‍🏫 โหมดติวเตอร์ (Instant Coaching Mode)**:
     - ขอ **💡 คำใบ้ (Hint)** เพื่อดูแนวทางโดยไม่เฉลยคำตอบทันที
     - ตรวจคำตอบทีละข้อ พร้อมอธิบายว่า **ทำไมตัวเลือกที่กดผิดถึงเป็นตัวลวง** (แยกประเภทความผิดพลาด เช่น ใช้สูตรผิด, คำนวณไม่ครบขั้น, อ่านโจทย์ไม่ละเอียด)
     - แสดง **🪜 วิธีคิดทีละขั้น (Step-by-Step Solution)**
     - กด **➕ ลองทำโจทย์คล้ายกันอีกข้อ** เพื่อสร้างโจทย์คู่แฝดในทักษะเดียวกันมาทดสอบความเข้าใจทันที
   - **📝 กระดานทดเลขในตัว (Scratchpad)**: วาดรูป ทดเลข หรือจดโน้ตประกอบการคิดได้บนหน้าจอ

3. **วัดผลละเอียดและวางแผนการเรียนอัตโนมัติ (Deep Analytics & Study Plan)**
   - **เกจวัดความพร้อมสอบเข้า ม.1 (Readiness Score)** เทียบเกณฑ์เป้าหมายโรงเรียนชั้นนำและห้องเรียนพิเศษ
   - **แผนผังเรดาร์ (Radar Chart) & แผนผังทักษะ (Skill Matrix)**: แสดงสถานะความแม่นยำรายทักษะ (`★ แม่นยำแล้ว`, `● กำลังฝึกให้คล่อง`, `◐ กำลังปูพื้นฐาน`, `↻ ควรทบทวนกันลืม`, `○ ยังไม่เคยฝึก`)
   - **วิเคราะห์นิสัยการทำข้อสอบผิด (Mistake Habit Diagnosis)** และ **📓 สมุดจดข้อที่เคยพลาด (Mistake Notebook)** พร้อมปุ่มฝึกซ่อมทันที
   - รองรับการโอนย้ายประวัติการฝึกเดิมจาก `backend/quiz.db` เข้าสู่ `backend/tutor.db` โดยอัตโนมัติ

## วิธีเปิดใช้งาน

```bash
python3 backend/server.py --port 8082
```

จากนั้นเปิดเบราว์เซอร์ที่ [http://127.0.0.1:8082](http://127.0.0.1:8082)

## การตรวจสอบคลังข้อสอบและระบบ

ตรวจความถูกต้องของแม่แบบข้อสอบและระบบทั้งหมด:

```bash
python3 -m backend.self_check
```

ตรวจเฉพาะบทหรือดูตัวอย่างข้อสอบ:

```bash
python3 -m backend.bank.check m.geo e.read --show 1
```

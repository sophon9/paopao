# เตรียมสอบเข้า ม.1

แอปฝึกสอบสำหรับนักเรียน ป.6 ที่เตรียมสอบเข้า ม.1 — **คณิตศาสตร์** และ **ภาษาอังกฤษ**

แต่ละชุดถูกสร้างใหม่จากแม่แบบที่ตรวจคำตอบได้ แล้วเก็บใน SQLite (`backend/quiz.db`) ข้อที่เคยอยู่ในชุดใดชุดหนึ่งจะไม่ถูกนำมาใช้อีก เพื่อไม่ให้จำเฉลยแทนการคิด

## วิธีเปิดใช้งาน

```bash
python3 backend/server.py --port 8082
```

จากนั้นเปิดเบราว์เซอร์ที่ [http://127.0.0.1:8082](http://127.0.0.1:8082)

ตรวจตัวสร้างข้อสอบด้วย:

```bash
python3 -m backend.self_check
```

## มีอะไรบ้าง

| โหมด | รายละเอียด |
|------|------------|
| คณิตศาสตร์ | 30 ข้อใหม่ · 40 นาที |
| ภาษาอังกฤษ | 30 ข้อใหม่ · 35 นาที |
| สอบรวม | 60 ข้อใหม่ · 75 นาที |
| ฝึกทีละบท | 8 ข้อใหม่ของหัวข้อที่เลือก |

- ข้อที่เคยออกในชุดใดชุดหนึ่งจะไม่กลับมาอีก
- นับถอยหลัง ส่งอัตโนมัติเมื่อหมดเวลา
- ตรวจคำตอบพร้อมวิธีคิดภาษาไทย และคะแนนแยกหัวข้อ
- บันทึกประวัติในฐานข้อมูลของเครื่องนี้
- คีย์บอร์ด: `1–4` เลือกคำตอบ · ลูกศรซ้าย/ขวา เปลี่ยนข้อ

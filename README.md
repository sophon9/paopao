# เตรียมสอบเข้า ม.1 สวนกุหลาบ

แอปฝึกสอบแบบสแตติก (ไม่ต้องติดตั้ง npm) สำหรับนักเรียน ป.6 ที่เตรียมสอบเข้า ม.1 สวนกุหลาบวิทยาลัย — **คณิตศาสตร์** และ **ภาษาอังกฤษ**

ทุกครั้งที่เริ่มสอบ แอปสุ่มข้อจากทุกบท เรียงลำดับใหม่ และสลับตำแหน่งตัวเลือก เพื่อให้ฝึกคิดและวิเคราะห์ แทนการจำว่าคำตอบอยู่ข้อไหน

## วิธีเปิดใช้งาน

### แนะนำ: ใช้เซิร์ฟเวอร์สแตติก

```bash
python3 -m http.server 8080
```

จากนั้นเปิดเบราว์เซอร์ที่ [http://localhost:8080](http://localhost:8080)

หรือใช้เครื่องมืออื่น เช่น `npx serve .` ก็ได้ ถ้าเปิดผ่าน GitHub Pages ให้อยู่ที่โฟลเดอร์ของเว็บไซต์

### เปิดไฟล์โดยตรง

เปิด `index.html` ด้วยเบราว์เซอร์ได้ แต่บางเบราว์เซอร์อาจจำกัดการโหลดสคริปต์จาก `file://` — ถ้ามีปัญหาให้ใช้วิธีเซิร์ฟเวอร์ด้านบน

## มีอะไรบ้าง

| โหมด | รายละเอียด |
|------|------------|
| คณิตศาสตร์ | 30 ข้อจากทุกบท · 40 นาที · ชุดใหม่ทุกครั้ง |
| ภาษาอังกฤษ | 30 ข้อจากทุกบท · 35 นาที · ชุดใหม่ทุกครั้ง |
| สอบรวม | 60 ข้อ (คณิตฯ แล้วอังกฤษ) · 75 นาที · แต่ละวิชาสุ่มใหม่ |
| ฝึกทีละบท | เลือกหัวข้อ · สลับข้อและตัวเลือก · จับเวลาแบบเลือกได้ |

- ธนาคารข้อสอบต้นฉบับ (ไม่คัดลอกข้อสอบจริง)
- ชุดถัดไปจะหยิบข้อที่ยังไม่เคยทำก่อน แล้วค่อยวนกลับมาเมื่อคลังข้อเริ่มหมด
- นับถอยหลัง ส่งอัตโนมัติเมื่อหมดเวลา
- ตรวจคำตอบพร้อมคำอธิบายภาษาไทย และคะแนนแยกหัวข้อ
- บันทึกประวัติ 30 ชุดล่าสุดใน `localStorage` พร้อมเทียบกับครั้งก่อน และชี้หัวข้อที่ควรกลับไปฝึก
- คีย์บอร์ด: `1–4` เลือกคำตอบ · ลูกศรซ้าย/ขวา เปลี่ยนข้อ
